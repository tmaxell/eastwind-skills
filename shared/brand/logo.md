# Eastwind logo

Source: `Brand Guidelines_L.pdf`, section 02, plus the SVG and PNG files shipped
with the open brand materials.

## Architecture

The logo is a mark (the "flower" of streams) plus the wordmark. The streams
converge on and radiate from a center; the elongated line of the mark reads as a
digital lens. Right angles stand for stable, verified solutions; the softness of
the curves for a flexible approach.

## Variants and files

Files live in `assets/logo/` inside the skill folder. All are the open set from
the brand materials.

| File | What it is |
| :--- | :--------- |
| `Logo EW light.svg` / `.png` | Full horizontal logo for light backgrounds. Mark `#382DDD`, wordmark `#201E3B`. |
| `Logo EW dark.svg` / `.png` | Full horizontal logo for dark backgrounds, monochrome. |
| `Logo EW light for e-mail.png` | Raster logo sized for email signatures. |
| `Logomark EW light.svg` / `.png` | Mark alone, light backgrounds, `#382DDD`. |
| `Logomark EW dark.svg` / `.png` | Mark alone, dark backgrounds, monochrome. |
| `icon EW SM black r.svg`, `… r-1`, `… r full` | Social avatar, dark version. Three corner radii: small, medium, fully round. |
| `icon EW SM white r 0`, `… r 8`, `… r full` | Social avatar, light version, `#F1F5F9` field with `#382DDD` mark. Radius 0, 8, and fully round. |

Both a color and a monochrome version exist for the horizontal logo and for the
mark. Use the compressed mark in small applications — Notion, Slack, Jira,
Discord, LinkedIn, social profiles.

Favicon set: `android-chrome-512x512`, `android-chrome-192x192`,
`apple-touch-icon`, `favicon-32x32`, `favicon-16x16`.

## Construction and clear space

| | Value |
| :-- | :---- |
| Mark construction | 80 px overall, with 28 px and 12 px internal steps |
| Horizontal logo construction | 430 × 80 px, 24 px step |
| Clear space, horizontal logo | X on every side, where X is the unit set in the construction |
| Clear space, mark alone | X on every side, with a 4X field in the extended version |
| Minimum size, horizontal logo | 24 px height |
| Minimum size, mark | 24 px |

## Never

- Distort vertically or horizontally.
- Add shadows.
- Rotate.
- Rearrange the elements.
- Recolor outside the approved variants.
- Set the wordmark in lowercase.
- Put the logo in a box.
- Change the size of the mark relative to the wordmark.
- Use the typography alone, without the mark.

Placing the logo on a plate is the one approved way to put it over a photo — see
[layout-and-graphics.md](layout-and-graphics.md).

## Pattern

A pattern is a plain alternation of the logo where the gap between elements equals
the element itself. It may be filled with any color from the brand palette and
exists in both a light and a dark theme.
